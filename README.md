## ✨ Особенности и преимущества

- ⚡ **Легковесность и экономия ресурсов:**
  - Исполняемый файл весит всего **~6.2 МБ**.
  - Потребление оперативной памяти: всего **35–45 МБ RAM** (в отличие от Electron-приложений, занимающих сотни мегабайт).
  - Сверхбыстрый нативный бэкенд на **Rust (Tauri v2)** и оптимизированный интерфейс на **React + Vite + Tailwind CSS**.
- 📡 **Умное обнаружение в локальной сети:**
  - Сканирование сервисов **mDNS** (`_adb-tls-connect`, `_adb-tls-pairing`).
  - Параллельное асинхронное сканирование подсети на порт 5555 (проверка 254 IP-адресов за 1–2 секунды).
  - Устройства в локальной сети остаются видимыми в отдельной колонке с цветными индикаторами статуса (🟢 Подключено, 🔴 Не подключено).
- 🔑 **Встроенная поддержка безопасности Android 11+:**
  - Удобный мастер сопряжения по 6-значному коду безопасности (`adb pair`).
  - Автоматическое определение IP-адреса и автоподключение сразу после ввода кода.
- 📁 **Молниеносный проводник файлов:**
  - SWR (Stale-While-Revalidate) кэширование открытых каталогов со временем отклика **0 мс**.
  - Фоновый предзагрузчик популярных каталогов (`/sdcard/Download`, `DCIM/Camera`, `Documents`, `Pictures`, `Music`).
  - Скачивание файлов с телефона на ПК в 1 клик, создание папок, удаление.
- 🎯 **Умная дедупликация эмуляторов:**
  - Автоматическое определение уникального PID процесса эмулятора в Windows.
  - Точное отображение реального количества запущенных эмуляторов без фантомных дубликатов портов (MuMu Player 12, LDPlayer, Nox, BlueStacks, Android Studio Emulator).

## 🚀 Быстрый старт (Запуск без сборки)

> [!TIP]
> Все готовые сборки и установщики доступны на странице **[GitHub Releases](https://github.com/dohobotov/TransFile/releases/latest)**.

Приложение поставляется со встроенными утилитами ADB (`bin/adb.exe`, `bin/AdbWinApi.dll`, `bin/AdbWinUsbApi.dll`). Устанавливать Android SDK отдельно **не требуется**.

Выберите удобный для вас вариант:

### Вариант 1: Портативная версия (Portable) — Рекомендуется
1. Скачайте **[TransFile-Portable.zip](https://github.com/dohobotov/TransFile/releases/latest)** или исполняемый файл **`TransFile.exe`**.
2. Распакуйте архив в любую удобную папку (папка `bin` должна находиться рядом с файлом `TransFile.exe`).
3. Запустите **`TransFile.exe`**.

### Вариант 2: Установщик Windows (Setup)
1. Скачайте инсталлятор **[TransFile-Setup.exe](https://github.com/dohobotov/TransFile/releases/latest)**.
2. Запустите установщик. Он установит программу в систему, добавит ярлык на рабочий стол и в меню «Пуск».
3. Программа готова к работе!

## 📱 Подготовка Android-устройства

### 1. Включение режима разработчика
1. Откройте **Настройки** на вашем смартфоне.
2. Перейдите в раздел **«О телефоне»** (или «Об устройстве»).
3. Найдите пункт **«Номер сборки»** (на Xiaomi/MIUI/HyperOS — «Версия ОС / Версия MIUI») и быстро нажмите на него **7 раз подряд**.
4. Появится уведомление: *«Вы стали разработчиком!»*.

### 2. Подключение по USB
1. В настройках перейдите в **«Система» → «Для разработчиков»** (или «Расширенные настройки» → «Для разработчиков»).
2. Включите пункт **«Отладка по USB»**.
3. Подключите телефон к компьютеру через USB-кабель.
4. На экране телефона появится запрос: **«Разрешить отладку по USB с этого компьютера?»** — отметьте галочку *«Всегда разрешать с этого компьютера»* и нажмите **ОК**.
5. Устройство сразу появится в первой колонке TransFile — **«Подключенные к компьютеру»**.

### 3. Беспроводная отладка (Android 11 и новее)
> [!NOTE]
> Компьютер и телефон должны быть подключены к **одной и той же сети Wi-Fi** (или одному роутеру).

1. Перейдите в меню **«Для разработчиков»**.
2. Найдите и включите переключатель **«Беспроводная отладка»** (Wireless Debugging).
3. Нажмите на саму надпись **«Беспроводная отладка»** (не на переключатель), чтобы открыть подробные настройки.
4. Вы увидите строку:
   - `IP-адрес и порт` (например, `192.168.1.119:39023`).
5. Нажмите пункт **«Подключить с помощью кода сопряжения»**.
6. Откроется всплывающее окно:
   - **Код сопряжения по Wi-Fi:** 6 цифр (например, `842190`).
   - **IP-адрес и порт:** динамический порт сопряжения (например, `192.168.1.119:42159`).
7. В приложении TransFile выполните сопряжение (см. инструкцию ниже).

### 4. Wi-Fi режим для Android 10 и ниже
1. Подключите телефон кабелем по USB один раз.
2. В TransFile на карточке телефона нажмите кнопку **«Включить Wi-Fi»** (выполняет `adb tcpip 5555`).
3. Отключите USB-кабель — телефон останется доступен по беспроводной сети через стандартный порт 5555.

## 🖥️ Инструкция по использованию

### Главный экран и колонки устройств

Интерфейс разделен на две логические зоны:
- **Левая колонка — «Подключенные к компьютеру»:**
  Отображает только устройства, имеющие прямое физическое соединение с данным ПК:
  - Устройства, подключенные по **USB**.
  - Локальные **эмуляторы Android**, запущенные на этом компьютере (`127.0.0.1:*`, `emulator-*`).
- **Правая колонка — «Обнаруженные в локальной сети»:**
  Отображает все Android-устройства, найденные в вашей домашней или рабочей сети Wi-Fi/LAN:
  - Рядом с каждым устройством отображается статус соединения:
    - 🟢 **Подключено** — устройство активно и готово к передаче файлов.
    - 🔴 **Не подключено** — устройство обнаружено в сети, но сессия ADB еще не установлена.
  - Кнопки управления: **«Подключить»** и **«Сопряжение»** (с иконкой ключа).

### Сопряжение по коду безопасности (Pairing)

Если ваше устройство на Android 11+ еще не сопряжено с компьютером:
1. В окне «Беспроводная отладка» на телефоне откройте **«Подключить с помощью кода сопряжения»**.
2. В TransFile на карточке устройства нажмите кнопку **«Сопряжение»** (или «Подключить»).
3. Откроется окно сопряжения:
   - IP-адрес устройства уже подставлен автоматически (например, `192.168.1.119:`).
   - Введите 5 цифр порта из окна телефона (например, `42159`).
   - Введите 6 цифр кода сопряжения.
4. Нажмите **«Подтвердить сопряжение»**.
5. TransFile автоматически завершит сопряжение, установит защищенное соединение и переведет статус устройства в 🟢 **«Подключено»**.

### Передача файлов и папок на устройство

1. В списке подключенных устройств выберите одно или несколько целевых устройств (отметьте чекбоксы).
2. Выберите файлы для отправки одним из способов:
   - **Перетаскивание (Drag & Drop):** перетащите файлы или папки прямо в окно программы.
   - **Кнопки выбора:** нажмите **«Выбрать файлы»** или **«Выбрать папку»**.
3. При необходимости укажите путь назначения на устройстве (по умолчанию: `/sdcard/Download`).
4. Нажмите **«Отправить»**.
5. В нижней части экрана отобразится прогресс отправки: текущий файл, процент выполнения, переданный объем и скорость передачи в МБ/с.

### Файловый проводник устройства

Для доступа к файлам на телефоне:
1. В верхнем меню перейдите на вкладку **«Проводник»**.
2. Выберите подключенное устройство из выпадающего списка.
3. Доступные возможности:
   - **Быстрые закладки:** мгновенный переход в популярные папки (`Загрузки`, `Камера / DCIM`, `Документы`, `Изображения`, `Музыка`).
   - **Хлебные крошки (Breadcrumbs):** кликните на любую промежуточную папку в строке пути для быстрого перехода вверх.
   - **Скачивание на ПК:** нажмите на иконку скачивания рядом с любым файлом — файл мгновенно сохранится в папку «Загрузки» на вашем компьютере.
   - **Создание папки:** кнопка «Новая папка» позволяет создать каталог в текущей директории.
   - **Удаление:** удаление ненужных файлов и папок с подтверждением.

### Работа с эмуляторами

TransFile полностью оптимизирован для разработчиков и пользователей эмуляторов:
- Поддерживаются **MuMu Player 12, LDPlayer 9, Nox, BlueStacks, MEmu, Android Studio (AVD)**.
- Встроенный алгоритм сопоставляет сетевые сокеты с системными процессами Windows (по PID) и предотвращает появление фиктивных копий одного и того же эмулятора.
- Если у вас запущено 6 копий эмулятора, в списке отобразятся ровно **6 независимых устройств**.

## 🛠️ Сборка из исходников

Для самостоятельной сборки проекта вам потребуются:
- **Node.js** (версия 18 или новее)
- **Rust & Cargo** (актуальная стабильная версия)
- **Visual Studio C++ Build Tools** (для сборки под Windows)

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-аккаунт>/TransFile.git
cd TransFile
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run tauri dev
```

### 4. Сборка релизных файлов
```bash
# Сборка исполняемого файла .exe
npx tauri build --no-bundle

# Сборка полного комплекта инсталляторов (NSIS Setup + MSI)
npm run tauri build
```
Готовые файлы будут сгенерированы в:
- `src-tauri/target/release/transfile.exe`
- `src-tauri/target/release/bundle/nsis/`

## ❓ Часто задаваемые вопросы и решение проблем (FAQ)

### Q: Телефон не отображается в списке локальной сети («Обнаруженные в локальной сети»)
1. **Проверьте Wi-Fi:** Убедитесь, что смартфон и компьютер подключены к одному роутеру.
2. **Изоляция клиентов (AP Isolation):** На некоторых роутерах включена опция «Client Isolation» / «AP Isolation», которая блокирует обмен данными между устройствами Wi-Fi. Отключите её в настройках роутера.
3. **Брандмауэр Windows:** При первом запуске разрешите приложению `TransFile` и `adb.exe` доступ к частным сетям.

### Q: При сопряжении Android 11+ возникает ошибка «failed to connect»
- **Обратите внимание на порты:** В Android 11+ порт сопряжения (в окне с кодом) и постоянный порт отладки (на главном экране беспроводной отладки) — **это разные порты**. Вводите в окно сопряжения именно тот порт, который указан во всплывающем окне с 6-значным кодом.
- Код сопряжения одноразовый: если вы закрыли окно с кодом на телефоне, сгенерируйте новый код.

### Q: Проводник файлов долго открывает папку
- В TransFile интегрировано интеллектуальное SWR-кэширование. При повторном входе в ранее открытую папку содержимое отображается **мгновенно (0 мс)** из оперативной памяти. Нажмите кнопку «Обновить», если на устройстве появились новые файлы.
